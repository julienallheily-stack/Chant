# Projet Chant

Projet Android de départ pour un programme de chant progressif sur 24 mois.

## Compilation sans Android Studio

Le projet est prévu pour être envoyé sur GitHub depuis un téléphone. GitHub Actions installe Java/Android SDK et compile automatiquement l'APK.

## Fonctionnalités prévues

- programme progressif 24 mois
- séances quotidiennes
- notifications discrètes orientées sport
- sauvegarde de la progression
- chansons françaises variées
- apprentissage phrase par phrase
- justesse, rythme et respiration
- interprétation (émotion, intention, nuances, dynamique)
- changements de tonalité
- enregistrement vocal
- suivi de progression
- objectif final : « Je l'aime à mourir »

Le ZIP contient une base Android compilable avec le workflow GitHub Actions.
